# gO2WAYS Corporate Website

Production-ready corporate website for **gO2WAYS** built using Next.js 15, React 19, TypeScript, and Tailwind CSS.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Architecture

- **Framework**: Next.js App Router (React Server Components by default)
- **Styling**: Tailwind CSS with CSS design token variables
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Form Management**: React Hook Form + Zod
